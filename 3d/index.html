Novo projeto 3D

Na primeira vez, o app precisa de uma chave do seu GitHub para publicar os projetos. É feito uma vez só neste aparelho.

  1. Toque em Criar chave no GitHub e entre na sua conta.
  2. Em Token name, escreva Eliel 3D. Em Expiration, escolha No expiration.
  3. Em Repository access, marque Only select repositories e escolha rdo-eliel.
  4. Em Permissions → Contents, escolha Read and write.
  5. Toque em Generate token, copie a chave e cole aqui embaixo.
